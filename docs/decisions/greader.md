# Google Reader 互換 API の廃止

- 状態：提案中
- 関連：[インセプションデッキ](../inception-deck.md)、[ユーザーと認証](accounts.md)、[MCP サーバー](mcp.md)

## 決定

1. **Google Reader 互換 API の提供は終了した。** `/accounts/ClientLogin` と `/reader/api/0/...` を撤去した。「好きなリーダーで読める」は製品の訴求から外す。
2. **日常の閲覧には公式の sendo-reader を使う。** 自作クライアントやスクリプトは REST API、エージェントは MCP から Sendo を使う。
3. **他のリーダーの優れた操作や読み方は、公式 Reader に取り込む。** 具体的な候補が見つかったら、sendo-reader の Issue で扱う。

## 理由

- 廃止を決めた時点で互換クライアントの利用者はおらず、日常の閲覧はすでに公式 Reader で行っている。
- 翻訳やワークスペースなど Sendo 固有の機能を互換 API 経由で届けるには、Sendo の応答に加え、外部クライアント側の対応も要る。
- 互換専用の認証、記事ごとの整数 ID、エンドポイントとテストの維持にかかる工数を、日常的に使う公式 Reader の改善に振り向ける。

## 検討した代替案

- **互換 API の提供を続ける。** Reeder や NetNewsWire などをそのまま接続できるが、利用者がいない間も、記事の取り込みや購読の仕様を変えるたびに互換の挙動を確かめる必要がある。

## 見直す条件

- 公式 Reader や REST API では満たせない具体的な外部リーダー連携の需要が出たとき。
